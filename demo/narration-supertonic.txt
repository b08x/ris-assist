# Format:
#   Lines beginning with #        comments, ignored
#   @section <name>               starts a section; each section renders to its

#                                 pauses are assembled, not synthesized)

#                                 by blank lines

# Numerals, times, and units are left as written. Supertonic 3 normalizes these
# natively — the README benchmarks it specifically against currency, phone

# different engine.
#
# Acronyms are the exception and are written as spaced letters, because there is
# no pronunciation-dictionary layer here. What you write is what it reads.

The skill carries forward the incident number, the original start time, and the scope. It leads with the delta: orders back, reports still queued. And it marks the cause suspected — the vendor says it was stuck, but no root cause is confirmed.

@section 05_knowledge

Incident S Y N zero one zero zero zero three zero. PowerScribe not sending transcribed reports to Synapse. The worklog spans three days. Remoted in. Awaited callback. Closed after user verification. Time worked: forty-four minutes.

@pause 0.3

The knowledge capture skill reads the worklog and builds the article around what it actually supports. The worklog documents a workstation layer fix — orphaned process, cache cleared, relaunched. That's one ladder rung.

The application layer, the interface layer, the advanced layer — nothing in the worklog supports those. The skill lists them as outstanding, not filled. It doesn't invent reproduction steps from general knowledge. That separation is the whole product.

@section 06_explain

The analyst is mid-incident and asks a domain question. The explain skill answers in one or two sentences and offers to go deeper. Shortest answer first, always.

@pause 0.3

"The order number identifies the request. The accession number identifies the imaging exam R A S and PACS actually performs. They're usually assigned by different systems, at different lifecycle stages, and are not interchangeable." That's it. The practical consequence follows in one more sentence.

@pause 0.4

Even mid-incident, the skill doesn't dump the full reference. It answers the question asked and offers to go deeper. That restraint is the contract.

The analyst is on alone overnight. The skill's first move isn't the differential — it's the change window question. Shift-change timing is when scheduled restarts and patching typically land. Knowing whether there was a window helps narrow this fast.
