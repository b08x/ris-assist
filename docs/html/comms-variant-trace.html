Where variant resolution diverges

One outage, two requests. Trace A — radiologists and techs — finds an exact variant and drafts in the site’s voice. Trace B — next shift — finds no variant (it is in the profile’s gaps) and substitutes the nearest one, disclosed aloud, rather than fabricating. The policy never stops early: it degrades, so no rule is ever “not reached.”
