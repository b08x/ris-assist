# Prompt 03 — Audience register: same fact, three readers

## ZONES
- Three vertical panels side by side, equal width, equal height. Each panel
  has the same three-row structure: header, lead-with sublabel, quote box.
- A thin footer band below all three panels.

## LABELS
### Left panel
- Header: CLINICAL
- Lead-with sublabel (verbatim from spec): "leads with the action they must take"
- Quote box (verbatim from spec):
  "Orders will not reach the modality worklist — use paper requisitions until further notice."

### Middle panel
- Header: TECHNICAL
- Lead-with sublabel (verbatim from spec): "leads with the failure, named precisely"
- Quote box (verbatim from spec):
  "ORM_O01 delivery to PACS is failing since 02:14; interface engine shows queue depth climbing."

### Right panel
- Header: LEADERSHIP
- Lead-with sublabel (verbatim from spec): "leads with scope, duration, what's being done, in that order"
- Quote box (verbatim from spec):
  "Imaging orders have been delayed sitewide for 40 minutes; engineering is restarting the interface engine now."

### Footer band
- Text: "Same fact. Different reader. The truth is unchanged."

## COLORS (macaron palette)

- TECHNICAL panel: soft lavender (#D4C5F9 approx) — precise
- LEADERSHIP panel: soft peach (#FFD4B8 approx) — executive
- Header text on each panel: dark slate (#1F2937 approx)
- Quote box: white (#FFFFFF approx) with 1px slate border (#E5E7EB approx)
- Footer band: light cream (#F5F1E8 approx)
- Body text: medium slate (#374151 approx)

## STYLE
- Flat comparison layout. Three columns of equal visual weight.
- Sans-serif body (Inter / SF Pro).
- Quote text in italic to mark it as a quoted example.
- Visual register: documentation reference card, not poster.

## ASPECT
16:9 landscape. Three side-by-side panels + footer band. Width comfortable
for ~30-word quotes per panel without truncation.

## NEGATIVE CONSTRAINTS
- No human figures, no avatars.
- No invented metrics or names — all numbers and system names come from
  the spec's example quotes verbatim (02:14, 40 minutes, ORM_O01, PACS).
- No emojis.
