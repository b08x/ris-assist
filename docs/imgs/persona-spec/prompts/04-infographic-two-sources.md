# Prompt 04 — Two sources, never blurred

## ZONES
- A fork diagram. A single trunk on the left labeled "claim", splitting
  into two branches — one going up-left to a destination box, one going
  down-left to a destination box. Both branches and their boxes are
  mirrored for visual balance.
- A footer band runs the full width below the fork.

## LABELS
### Trunk (left)
- Source node label: "claim" (small, monospace-style)

### Upper branch
- Path label on the branch: "site-specific"
- Destination box title: "SITE PROFILE"
- Destination box body (verbatim from spec):
  "Not in your site profile — never invented."

### Lower branch
- Path label on the branch: "generic domain"
- Destination box title (verbatim path): "`references/`"
- Destination box body (verbatim from spec):
  "Answer generically, say so."

### Footer band
- Text (verbatim from spec):
  "Mixing without marking which is which is a defect, not a style issue."

## COLORS (macaron palette)
- Trunk and branches: muted slate (#9CA3AF approx) — neutral routing
- Upper branch (site-specific): soft mint green (#B8E6D2 approx)
- Lower branch (generic): soft lavender (#D4C5F9 approx)
- Destination box backgrounds: white (#FFFFFF approx) with 1px slate
  border (#E5E7EB approx)
- Destination box titles in bold dark slate (#1F2937 approx)
- Path labels (site-specific, generic domain) in italic medium slate
  (#4B5563 approx)
- Footer band: light cream (#F5F1E8 approx)
- Background: off-white (#FAFAF5 approx)

## STYLE
- Flat fork diagram. Clean rectangles for destination boxes, thin lines
  for the trunk and branches.
- Sans-serif body (Inter / SF Pro). Path labels in italic.
- Monospace (JetBrains Mono style) for `references/` — it's a path.
- Visual register: documentation reference card.

## ASPECT
16:9 landscape. Fork opens from right (trunk) to left (two destinations)
or trunk on left, destinations on right — either reading direction works,
the prompt asks for whichever composes most naturally with the macaron
palette.

## NEGATIVE CONSTRAINTS
- No "vs." framing — the two sources are complementary, not opposed. No
  red-vs-green color choice; both boxes are equally valid destinations.
- No human figures.
- No emojis.
